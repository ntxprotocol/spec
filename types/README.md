# Known types

Known types are shared field structures, so apps from different makers understand each other
without talking first. Each type has a short document and a type descriptor (`*.ntxtype.json`).

| Type | Status | What it is |
| --- | --- | --- |
| [`ntx.text`](ntx.text.md) | Pre-Draft | A single piece of plain text |

Want a new known type? Open a *Proposal* issue. Your own products can always use a custom
reverse-DNS type (for example `com.example.announcement`) without asking anyone.
